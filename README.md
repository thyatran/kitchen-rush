# Kitchen Rush 🍳

A 2D, single-player restaurant management game built with Python and Pygame for CS 122 at San José State University.

## About the Project

Kitchen Rush is a fast-paced cooking game inspired by Overcooked. Players control a chef who prepares ingredients, cooks dishes, and serves customer orders before time runs out.

The goal is to complete as many orders as possible while managing time and kitchen tasks efficiently.

## Planned Features

- Chef movement and interaction with kitchen stations
- Ingredient preparation (chopping and cooking)
- Recipe assembly and order fulfillment
- Customer orders with countdown timers
- Scoring system with penalties for missed orders
- Two levels with increasing difficulty
- Start menu, game-over screen, and sound effects

## Technologies

- **Language:** Python
- **Game Library:** Pygame
- **Data Storage:** JSON
- **Version Control:** Git and GitHub

## Installation

1. Clone the repository.
2. Install the required dependency:

```bash
pip install -r requirements.txt
```

3. Run the game:

```bash
python main.py
```
